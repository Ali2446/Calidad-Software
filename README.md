# Control-Calidad-Software
Proyecto de evaluación

Manual de Usuario – Calculadora
1. Introducción
Este manual proporciona una guía para la instalación y uso de la calculadora. El sistema permite realizar operaciones matemáticas básicas y algunas funciones científicas, dependiendo de la versión implementada.

2. Requisitos del sistema
Hardware mínimo:

Procesador: 1 GHz o superior

RAM: 1 GB

Espacio en disco: 50 MB

Software:

Sistema operativo: Windows, macOS o Linux

Python

Editor 

3. Instalación
Descargue el archivo del repositorio (desde GitHub, por ejemplo).

Instale Python (si no lo tiene): https://www.python.org/

Abra la terminal o consola de comandos.

Navegue a la carpeta del proyecto.

Ejecute el archivo principal llamado python calculadora.py

4. Uso del sistema
Pantalla principal:

Se presenta una interfaz con botones numéricos (0–9), operaciones (+, –, ×, ÷) 

Pasos para realizar una operación:

Ingrese el primer número usando el teclado o los botones.

Seleccione una operación (por ejemplo: +).

Ingrese el segundo número.

Presione el botón = para ver el resultado.

5.Errores comunes

“ZeroDivisionError”	Causa: Intento de dividir entre cero	Solucion: Verifique los operandos
“SyntaxError”	Causa: Error de escritura en el código	Solucion: Revise los signos y valores
“Pantalla congelada”	Causa: Error de ejecución	Solucion: Reinicie la aplicación
